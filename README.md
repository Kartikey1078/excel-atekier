# ZHA Homepage Replica (Educational)

A Next.js + TypeScript + Tailwind CSS recreation of the visual structure and editorial layout of [zha.com](https://www.zha.com/), using original placeholder copy and stock imagery.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

This project is not affiliated with Zaha Hadid Architects. Branding, text, and images are placeholders for learning and demonstration.
